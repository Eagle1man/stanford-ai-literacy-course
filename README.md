Язык максимально простой, без кода и формул. Все шесть страниц (3 онлайн-теста курса + 3 занятия) прошли автопроверку `#selftest`: 60 из 60 на каждой.

Как пользоваться: открыть ссылку → вкладка **«Лекция»** (слайды листаются стрелками ← →; под каждым слайдом — подробные заметки преподавателя) → вкладка **«Тест · 60 вопросов»** (вопросы по одному, выбор кликом или клавишами 1–4, в конце — результат и разбор каждой ошибки). Страница работает без интернета: можно скачать и открыть локально.

Для проверки файла добавьте к адресу `#selftest` — страница ответит на все 60 вопросов и напечатает `SELFTEST score=6000 correct=60 total=60 answered=60`. Все три страницы прогнаны в headless Chrome: 60 из 60 на каждой.
